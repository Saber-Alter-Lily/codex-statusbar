# 实际代码审计后的修复

本轮针对源码路径、干扰用户工作和诊断泄露面修复，并非安全认证。此前 326 项 Windows 合成测试通过记录属于前一版本，保留原报告。本轮新增及既有合成测试已在隔离 Windows CI 通过，见末节。

## 已实现

- EXE 在解析配置之前拒绝所有 `--probe` 和 `--*-probe`（含 IPC 探针），只保留合成 `--self-test`。仓库中的独立开发脚本仍不是用户包的一部分，不应任意执行。
- 调试默认关闭；32 条有界异步队列，每条最多 16 Ki 字符，磁盘日志约 1 MiB 加一份备份。忙时丢弃，退出不阻塞等待；自由文本位置/生命周期详情不再记录。正常格式化诊断仍隐藏标题、标识、路径、UIA 名称和错误文字。
- 失配会话查找按 ID 负缓存、2–60 秒退避，全局扫描间隔至少 1 秒，单轮不重复扫描；watcher 变化可重新触发。扫描合作预算为 2048 项、128 目录、12 层、16 候选、100 毫秒，停止时取消。预算截断不等于没有会话；大目录中可能无法发现目标，不能据此显示零速度。
- UIA 遍历所有兄弟循环共享 4000 节点、30 层、16000 步、250 毫秒预算；找不到控件按 1/2/4/8/10 秒退避，失焦、手动隐藏或非停靠模式停止昂贵发现。单个已经阻塞的系统/UIA 调用无法被上述合作预算强制终止。
- 位置快捷键默认关闭，托盘可明确启用；只在 Codex 前台注册且派发时再检查，失焦注销。取消从自动停靠进入的编辑恢复原模式，重启参数逐项使用 ArgumentList 保留空格、Unicode 与引号。
- sessions、数据库、设置和日志限本地普通路径。UNC、设备命名空间、映射网络盘、ADS 及路径中的 reparse point 被拒绝；reader 每次打开前重验，并在读取前比对已打开句柄的最终路径。相同用户进程的竞态仍不构成严格隔离边界。
- 应用本程序集的已知系统 DLL 以 System32 绝对路径解析，并限制依赖搜索；不改变框架自己的原生缓存加载策略。
- IPC 初始化前核对管道服务端 PID 所属 Windows 包身份；连接期间持有进程句柄并检查存活及管道绑定。身份查询失败、非打包开发版或包家族变化时拒绝该通道、清除旧路由并回退日志模式。日志模式不保证与前台对话实时同步。帧与路由表也设上限。

## 验证范围

增加合成路径/句柄、注入的文件系统拒绝探针、预算/退避、诊断真实路由和假秘密输出、重启参数、默认热键、独立随机命名管道拒绝等回归检查。它们不访问真实 Codex 管道、配置、会话、账号或模型。CI 对源码构建和最终自包含 EXE 分别运行测试，包内许可、清单、源码提交和 ZIP hash 继续验证。

本机无 .NET/Windows，不在本机宣称运行通过；静态 guards 不是运行测试。真实 Codex 最新版本、UI 视觉、快捷键与窗口切换、真实注册表迁移及打包客户端 IPC 仍待用户桌面验收。日志解析期间正文可能进入内存，不能声称只接触计数。未发布正式 Release、未合并 main、未安装用户设备。
