## 本轮已改

- **开机启动必须明确选择**：首次启动默认关闭；增加 `startupOptInConfirmed`。上游曾自动写入的启用设置不视为用户同意，首次迁移会移除同名旧 Run 注册项；用户通过托盘或 `--install-startup` 明确启用后才恢复。关闭后不会自动重新开启。沿用上游同名注册项，故本分支与原版不宜并行使用。
- **主题最小权限**：删除整个 Codex 配置主题读取器及依赖真实配置的自测。Auto 只跟随 Windows；若 Codex 主题不同，可手动选深/浅色。不再仅为主题读取可能含凭据的配置文件。
- **诊断最小披露**：常规 `--debug`/headless 输出中线程、回合、标题、路径、UI 元素名称、异常与自由文本警告字段整体替换为 `[redacted]`；自由文本事件只保留时间和发生事实。没有偷偷开启的“详细敏感日志”模式。代价是定位某些故障信息更少。
- **IPC 探针**：C# 探针不再输出帧、线程 ID 或异常详情，底层诊断 tap 也不转发原始负载。Node 探针只输出固定类别计数，不回显任意服务端字符串；默认不写文件，`--log NEW_FILE` 使用独占创建，不追加/覆盖旧文件。POSIX 请求权限 0600；Windows ACL 仍由系统和目录继承决定。旧版已生成的日志不会被自动删除，请勿公开分享。
- **隔离目录**：显式 sessions 根目录缺少同级 SQLite 时不回退个人默认数据库。数据库提供的 rollout 路径必须是根目录内的 `.jsonl` 文件，拒绝路径穿越和所检路径组件的 reparse point。不能防御同一用户在检查之后替换文件的竞争条件。
- **TTFT 终端可见**：`--no-overlay` 状态变化时打印 TTFT（毫秒）；只有上游 `time_to_first_token_ms` 存在且非负才显示，标注 reported / not locally estimated。缺失显示 `-- (not reported)`，不会拿第一条日志时间伪装首 token。新回合清空旧值。展开详情新增 TTFT（上报值）行，缺失明确显示未上报；不改变常驻条/设置。该 UI 尚未实机验证。
- **TPS 诚实口径**：终端、诊断和展开指标名称明确为“模型阶段估算（含推理）”，不是逐 token 流式速率。分母来自 Reasoning/AgentMessage 阶段时间窗口；部分旧日志起点由事件边界推导，可能含前处理/等待，不能保证等同纯解码时间。紧凑浮条仍沿用 `tok/s` 单位及 `~` 暂存标记，完整语义见展开名称和本说明。
- **开发工具护栏**：`probe_appserver.mjs`、`groundtruth_tps.mjs` 默认拒绝运行，必须显式传 `--allow-live-inference`。它们仍会继承认证、发送提示词、产生费用/原始输出，不是只读安全测试。新增 probe 输出忽略规则（不能移除已跟踪的历史数据）。
- **构建失败关闭**：缺少自测程序、Python 或 fixture 检查失败时不继续发布；显式 `-SkipTest` 仍可跳过，产物应视为未验证。
