# 本地用量与速度浮标和面板：1.1.0-local.6

这是指定加固分支上的本地测试升级，不是正式 Release。程序不需要 API key，不发起模型请求，不读取登录凭据。只读本地会话用量日志、有限数据库元数据和经过进程与包身份校验的 IPC。

## 使用

正常启动会打开可调整大小的面板并显示任务栏窗口。关闭、最小化或点击“退至托盘”只隐藏面板；点击托盘或再次启动同一 EXE 可重新打开同一个面板。“退出监测”才结束面板、浮标和读取。托盘仅保留打开与退出；原浮条位置设置在面板的“浮条与高级设置”中。

浮标默认显示阶段估速、累计 token、累计缓存命中和 TTFT。面板中可逐项勾选，选择保存在原设置文件的可选 compactFields 字段中，不修改位置、锚点或偏移。还可选择“最新请求 / 窗口”，它使用客户端上报的最近请求大小和窗口值，缺失显示 --，不使用累计 token 代替上下文。浮标标注手动锁定与短 ID，等待计数、空闲以及上轮 TTFT 分别标注。

手动定位浮标也按当前勾选文本的实际字宽布局；不再使用旧的固定宽度裁掉新增字段。原锚点和偏移保持不变。

表格显示近期发现的本地会话，最多 8 条，使用本地短 ID。双击一行或点击“选择并锁定会话”后，概览读取该会话；“返回自动跟随”会立即清除手动概览。所选会话约每 350ms 检查增量，后台每秒最多处理一个事件路径和一个已知会话，8 条会话的轮转通常约 8 秒，慢 IO 或事件队列可能增加延迟。

启动时只查询最多 8 条近期数据库元数据（不读取标题，查询有时间与等待预算），以后通过有界文件事件队列增量发现。列表不是全部历史会话。非当前且长期无变化的会话约 10 分钟后淘汰。面板开关不触发全历史扫描。

## 数据含义

- 累计输入、累计输出、缓存输入来自该会话的官方计数。合计为输入加输出；缓存输入已经包含在输入中，不再相加。这些不是订阅余额或上下文占用百分比。
- 本轮输入和缓存只在能可靠取得本轮计数或累计差值时显示；未知显示 `--`。缺少明细时可显示数据库提供的总量，同时明确标注明细未知。
- 速度是官方输出计数除以客户端记录的模型阶段区间并集，包含推理，标注为“事件推算（低可信）”。生命周期事件的起点可能由客户端事后补造，尚无独立匹配的流开始证据；这个数不是严格实测生成速度，也不是逐 token 流速或网络 TTFT。无法形成有效区间或缺少计数时间时显示 `--`。
- 15 秒无新用量计数后，浮标明确改为“上次”并保留计数年龄；完成记录后的值标为“上轮”。计数时间是客户端用量记录时间，不保证就是模型输出的完成时间。状态只说明计数是否更新，不判断任务是否仍在运行。阶段记录可能相隔数十秒，工具阶段可能长时间没有新计数。
- 现代响应按 response_id 去重，跨载体仅用完整的累计检查点关联；不同响应即使用量相同也分别计数。缺少身份和累计检查点的旧记录不用于逐响应求和，仍可使用可靠的本轮计数或累计差值。会话累计值始终替换而不累加。
- 同一日志发现有效的现代 thread_token_usage 后，累计计数与速度分子优先该载体；旧 token_count 继续提供可用的请求/窗口元数据，不覆盖现代累计值、不刷新现代用量时间、不再重复计入响应分子。现代载体出现前的旧式响应检查点会撤回，避免两种不同步的计数体系混算。
- 只有新的有效用量记录才折入阶段估速。单独到达的模型阶段完成事件不使用旧 token 分子重算速度，避免计数时间未变而速度自行变化。
- TTFT 只显示客户端明确上报的回合字段。没有逐模型调用的首字字段时显示“未上报”，不把工具阶段边界或生命周期起点冒充精确首字时间。
- 更新时间依据相关事件的时间戳。文件修改时间只在缺少事件时间时回退使用，因为写入句柄未关闭时 mtime 可能落后。
- 日志活动时间与用量计数时间分开显示。主状态只说明计数是否更新，不再把缺少结束记录解释为仍运行或已停止。监测检查时间来自完成的读取，不用 UI 时钟冒充；另显示日志是否已读到已观测末尾。

## 前台归属的限制

当前客户端 IPC 的订阅标识没有可验证的原生窗口 HWND 对应关系。因此本版自动模式明确显示“前台会话未识别”，不会把最近的广播或数据库记录当成当前页面。IPC 只用于发现候选会话；用户可以明确选择“锁定 IPC 候选”。多窗口不再按最新广播抢占会话。Dot 或云端页面没有可读本地日志时不支持，不能继承其他任务的数据。

这个限制没有通过合成检查消失，真实前台自动跟随仍未实现。手动锁定和多会话增量监测可以独立使用。

## 验证与回退

新增合成回归覆盖：空路由、断连、多订阅、锁定切换、返回自动、无新计数时失效、事件时间独立于文件修改时间、面板关闭与重复使用、取消后的迟到结果。保留原路径与本地 DLL、IPC 身份、脱敏日志、扫描预算、默认关闭自启和快捷键等约束；所有 probe CLI 继续禁用。

升级采用独立目录，保留旧包及原设置备份。回退时退出新版监测程序，运行保留的旧版 EXE；如果修改过设置，再恢复备份的 settings.json。不要覆盖正在运行的程序。具体本地部署与验收结果另见交付说明；本文件不包含真实会话 ID、正文或用户路径。
