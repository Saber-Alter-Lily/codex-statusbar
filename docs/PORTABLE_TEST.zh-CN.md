# CodexStatusbar Windows x64 免安装测试包

这是测试包，不是正式 Release，也没有代码签名或安全认证。适用于 Windows x64；不需要另装 .NET，不要求管理员权限。最新版 Codex Desktop 的实际兼容性尚未验证，不能承诺解压后一定立即出现指标。

## 怎么使用

1. 从本仓库对应成功的 GitHub Actions 运行页面下载 portable-test artifact。GitHub 网页下载可能要求登录 GitHub；这仅用于下载，与状态条运行账号无关。若外层 artifact ZIP 内还有以 CodexStatusbar-win-x64-test 开头的 ZIP，继续解压内层 ZIP。
2. 把测试包完整解压到普通用户可写的文件夹，不要直接在压缩包中运行。
3. 先打开 Codex Desktop，使用你原来的 Codex 账号正常进行一次对话，让本机会话目录存在；再双击 `CodexStatusbar.exe`。不要同时运行上游原版状态条。
4. 状态条会尝试跟随当前 Codex 对话。右下角托盘可能收在隐藏图标中；右键可查看“多会话速度 · 近期观察”，最多八条。先打开的无写入历史会话不会全部自动列出；切到某个对话或有新日志写入后才可能发现。
5. 用完从托盘选择退出。没有安装器或服务；退出后可删除解压文件夹。

**状态条本身不需要登录账号，也不需要填写 API key。** 它读取本机 Codex 的会话元数据/用量日志和本地 IPC，不代替 Codex 登录，不调用模型接口。Codex 自己的登录与使用要求仍由 Codex 管理。

新配置默认不开机启动；只有你明确使用托盘开机启动选项或对应命令才启用。如果之前已经明确启用过，本次会沿用该选择；旧版自动启用的配置不视为同意。程序会写自己的本地设置，.NET 单文件运行时可能解压到临时缓存，因此“免安装”不等于完全没有本地文件写入。默认设置目录为 `%LOCALAPPDATA%\CodexStatusbar`；不要把个人设置或日志随测试包转发。

## 数字是什么意思

- TPS 是含推理的模型阶段速度估算，不是逐 token 流式解码测速；不要把多个会话的速度相加。
- TTFT 只有日志上报时才显示，缺失是 `--`，不代表零；新回合清除旧值。
- 多会话列表十五秒无日志新写入会隐藏实时 TPS，并标注历史状态；这不代表模型一定停止工作。
- `--`/等待数据可能是日志尚未写入、缺少可用字段、会话不在发现范围，或者当前 Codex 内部格式发生变化，不要把缺失当成真实测速结果。

## 没有显示时

先确认 Codex Desktop 已打开且有实际对话，再退出并重新打开状态条。首次启动状态条时如果会话目录还不存在，之后创建目录不会自动补建 watcher，重启状态条可重新连接。

Auto 主题跟随 Windows，不读取 Codex 主题配置；如果两者配色不同，可在托盘手动切换深/浅色。自定义 `CODEX_HOME` 需要由启动状态条的环境继承；高级用法可通过 `--sessions` 指定根目录，普通默认安装无需配置。

如果仍失败，请提供 Codex 的准确版本、Windows 版本、现象和必要的已脱敏截图。不要上传会话正文、API key、完整个人日志或配置文件。不要为了运行本测试包关闭系统安全防护；如出现拦截，保留提示并先核对来源和反馈。没有要求管理员权限的正常步骤。

## 如何核对包

- `BUILD-INFO.json` 记录实际构建提交、PR head、CI运行入口和发布后 EXE 的合成自测结果。
- `SHA256SUMS.txt` 列出包内其他文件的 SHA256；外部 `.zip.sha256` 对应内层测试 ZIP。
- 可用 PowerShell `Get-FileHash -Algorithm SHA256 <文件>` 比对；校验和可发现传输损坏，但不等于代码签名或安全认证。
- 包含项目原许可证、第三方声明及随自包含 .NET 分发的许可声明，不应删除。

CI 仅做隔离的合成数据测试，包括对最终自包含 EXE 的自测、x64 PE 检查及 ZIP 解压回读哈希检查。没有连接你的电脑、读取真实会话、调用模型或安装程序；尚未验证真实最新版客户端、浮条视觉、多 DPI、实际注册表迁移和完整桌面交互。

## 审计修复后的行为变化

- 位置快捷键默认关闭。可在托盘明确启用，且仅在 Codex 前台时注册。后台不再保留该组合；编辑请用浮条保存/取消。
- 仅支持本地磁盘上的普通路径；网络共享、映射网络盘、设备路径、符号链接/junction 配置会被拒绝。自定义 `CODEX_HOME` 与 `--sessions` 同样受限。
- IPC 校验管道服务端 PID 对应的 Windows 包身份。非商店/开发者版、包身份改变或无法读取身份时，进入日志模式；这不代表已实时同步当前前台对话。
- 所有 `--probe` / `--*-probe`（含 `--ipc-probe`）入口已禁用；不要使用旧开发文档中的探针命令。
- `--debug` 默认关闭。开启后采用有界异步队列，当前日志最多约 1 MiB，加一份同等上限备份；繁忙/退出时可能丢诊断。自由文本诊断详情统一隐藏。
- 源码解析日志时，正文仍可能暂时进入进程内存。无模型调用不等于完全不接触会话内容。
- 原有 326 项通过是上一版本证据，新修复的构建与合成结果见 [审计修复记录](AUDIT_FIXES.zh-CN.md)。
